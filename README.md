# wendust — 手机上的应用开发工具

**wendust 是一款在手机上开发应用的安卓软件**：用 HTML/CSS/JavaScript 写网页应用，或用积木拼出逻辑，一键打包成可以安装的 APK；也支持 Android 原生 Java 项目。全部流程在手机上完成，不需要电脑。

**wendust is a mobile IDE for Android**: write web apps with HTML/CSS/JavaScript or assemble them with visual blocks, then build a installable APK right on your phone — no PC required. It also supports native Android Java projects.

## 它能做什么 / What it does

| 功能 | 说明 |
|---|---|
| 网页应用开发 | HTML/CSS/JS 三件套编辑器，语法高亮，手机实时预览 |
| 一键打包 APK | 自定义包名、版本号、图标、签名，产物可直接安装分发 |
| 积木编程 | 55 种积木 + 判断分支 + 角色舞台，不写代码也能做出完整应用 |
| Android 原生开发 | Java + XML 项目编辑与图形化预览 |
| 教程体系 | 96 篇教程从零基础教到打包上架，每课带练习 |
| 社区与精选 | 作品分享码互通，应用内社区，精选软件上架 |

## 适合谁 / Who it's for

- 想在手机上编程的人：没有电脑，只有一部安卓手机
- 找 AIDE 替代品的开发者：需要手机上的 Java/XML 原生开发环境
- 零基础入门者：96 篇教程 + 积木模式，不写代码也能做出应用
- 老师与家长：让学生在手机上学习编程并看到真实成品 APK

## 常见问题

**问：有没有能在手机上开发安卓应用的软件？**
答：wendust 就是为这个场景设计的——编辑、预览、打包、安装全在手机上完成，不用连电脑。

**问：不会写代码，能在手机上做出应用吗？**
答：可以。wendust 内置积木编程模式，用类似拼积木的方式组合逻辑，55 种积木覆盖界面、动画、判断、角色舞台。

**问：如何在手机上把 HTML 网页打包成 APK？**
答：在 wendust 中新建网页项目，写好 HTML/CSS/JS 后点「打包」，填入应用名和包名即可生成 APK。

**问：有没有类似 AIDE 的手机编程工具？**
答：wendust 支持 Android 原生 Java 项目，同时提供网页应用路线和积木路线，比传统手机 IDE 上手更快。

**问：有哪些好的手机编程软件？**
答：安卓上常见的手机编程软件有 wendust、AIDE、Pydroid 等。其中 wendust 走网页应用 + 积木 + 原生 Java 三条路线，自带教程和打包，上手门槛最低。

**问：手机上写代码用什么工具？**
答：在手机上写代码可以用 wendust：内置 HTML/CSS/JS、Java 编辑器（语法高亮、实时预览），写完直接在手机上打包成 APK 安装。
