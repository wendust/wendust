wendust 网页版停止运营公告

致亲爱的用户：

自 wendust 网页版上线以来，我们与每一位在浏览器里写下第一行代码的创作者一起，走过了很长的一段路。从打开网页、新建项目的第一秒，到写下第一个标题、第一段样式、第一行脚本；从一次小心翼翼的预览，到第一次成功把作品打包成 APK——网页版陪着很多朋友完成了从"我想做个应用"到"我的应用已经跑起来了"这最重要的一步。你们在课堂上传阅的作品、在深夜里改到完善的页面、分享给朋友的第一个小游戏，都是这段路上最珍贵的风景，也是 wendust 一直往前走的全部理由。

回望这段时间，网页版承担了它独特的使命：让没有任何安装条件的设备也能立刻体验创作的完整流程，让"试一试"的门槛降到几乎为零。无数第一次接触编程的用户，正是从浏览器里的那个编辑器开始，认识了我们引以为傲的打包能力、云端账号与免费云端空间。可以说，没有网页版的桥梁，就没有今天 wendust 手机端的千万次安装与使用。它完成了一次几乎不可能完成的任务，而且完成得很好。

但是，由于团队精力有限，网页版与手机端双线维护的成本越来越高：同样的一个功能，要在两套完全不同的运行环境里各做一遍、各修一遍、各测一遍；同样的一个问题，要排查两份完全不同的日志。资源被分散之后，两个版本都难以做到极致。为了对每一个认真使用 wendust 的用户负责，为了把全部的时间、算力与心力都投入到手机端体验的打磨与更新上，经过反复权衡与慎重评估，我们不得不做出如下决定：

在此，非常遗憾地宣布：wendust 网页版即将停止运营。

需要特别说明的是：本次下线不影响 wendust 手机 App 的任何功能——您的本地项目、本地数据、免费云端空间、云端账号、已打包的全部 APK，都将继续正常使用，与过去完全一致。手机端不仅不会停，反而会以更快的节奏更新：今天刚刚上线的课后答题与错题本、积木舞台、离线原生编译，都是这份承诺的证明。

具体时间安排如下：

1、即日起，网页版不再新增任何功能，仅保留现有能力供大家过渡使用，期间出现的问题将不再逐一修复，请您谅解；

2、预计 2026 年 11 月 18 日 10:00 正式关闭网页版在线服务，届时网页版将无法访问，在线编辑、预览与打包能力将一并停止；即日起在线版入口已停止服务；

3、关闭前，请务必把您在网页版创建的项目逐个导出备份，或迁移到 wendust 手机 App 中继续创作，以防数据丢失。迁移方式非常简单：在网页版把项目导出为 ZIP，再用手机 App 的"从备份恢复"导入即可，一分钟就能完成。

关于大家可能关心的几个问题，也一并说明：网页版的免费云端空间在关闭后由手机 App 的免费云端无缝承接，账号体系完全一致，无需重新注册；已购买或抽奖获得的云端扩容、语法槽位、限定称号等权益，全部在手机端继续生效，一分不少；过去在网页版遇到的任何遗留问题，欢迎通过手机 App 内的联系方式反馈，我们会认真对待每一条留言。

对于本次下线给各位带来的诸多不便，我们致以最诚挚的歉意。收缩战线从来不是因为退缩，而是为了把一件事做到极致——手机端会带着网页版的那份心意继续前进，以更快的更新、更稳的体验、更多的新功能，回报每一位留下的用户。

最后，再次感谢每一位使用过、支持过、陪伴过 wendust 网页版的你。江湖不远，手机端见！

这是什么

wendust 是一个安卓应用，用来在手机上开发应用。你可以编写 HTML、CSS 和 JavaScript 做网页应用，随时切换预览看效果，最后把整个项目打包成 APK 安装包；也可以选 Android 原生路线，用 Java 和 XML 写界面，带语法高亮和图形化预览。写代码到打包安装，全程在手机上完成。

它的定位是小项目和随身修改：做一个计算器、一个展示页面、一个小游戏，或者在任何有手机的地方改几行代码。它定位于轻量开发场景，具体边界见下文说明。

除了手机 App，wendust 还有两个兄弟版本。电脑版（在浏览器打开 pc.html 即可使用）提供和手机版一致的项目管理与打包能力，支持直接打包 APK、Windows EXE 和 macOS DMG 三种格式，每日 10 次打包额度；在线版无需安装任何东西，打开网页就能写代码、一键分享。三个版本的项目通过分享码互通：手机上生成分享码，电脑版或在线版粘贴导入，反过来也一样。

适合想给自己做小工具的人、学开发的学生、出门在外要改代码的开发者。

主要功能

原生安卓绿界面（v14）

整体视觉参考 AIDE 重做：绿色工具栏、绿色主按钮、浅绿底色，深色模式同步换装，历史自选主题色自动迁移。启动器图标同步换绿。

HTML 教程（v14）

内置 96 篇 HTML 教程，12 个章节覆盖从入门到精通：初识 HTML、文本格式、列表、链接图片、表格、表单、语义化、多媒体、HTML5 进阶、SVG 与 Canvas、CSS/JS 协作、最佳实践。每篇都有动手练习：看讲解、写代码、一键运行看效果，还能对照参考答案。全程离线，不用联网。

自定义语法（v14）

设置 → 语法：内置 xml、java、css、html、js 五大语法（不可删除、不可调整）。你可以创建自己的语法：起名字，然后为每个语法标记填上对应的 HTML、CSS 和 JS——运行时不解释你写的内容，直接按映射替换，预览和打包 APK 都生效。编辑器里自定义标记有专属高亮。限额：每 5 个月最多创建 1 个语法，每个语法每 7 天只能改 1 次名。

项目管理

创建、重命名、删除项目，更换项目头像。每个项目有独立的文件目录，所有文件存在手机本地。

项目类型（v5.5）

新建项目时先选路线：HTML 网页或 Android 原生。选网页就从七个模板起步；选原生则直接生成 Java + XML 骨架（AndroidManifest、MainActivity、activity_main.xml），生成完整的骨架，直接可改。

Android 原生开发（v5.5）

原生项目里用 Java 写逻辑、XML 写界面，两者都有语法高亮。原生项目新建文件时只提供 .java 和 .xml 两种类型，保持工程纯净。界面布局用图形化预览查看：解析你的 layout XML，把 TextView、Button、输入框、进度条等真实控件渲染到屏幕上——文字、颜色、图形、圆角、点击事件都能呈现，按钮按下去会触发对应的 onClick 演示。

模板

HTML 项目可以从模板开始：空白项目、计算器、待办清单、企业官网、个人主页、产品展示页、博客。模板提供完整的三个文件（index.html、style.css、script.js），结构可以直接用，把文字和图片换成自己的内容就是一个能用的页面。

代码编辑

语法高亮、代码补全、撤销重做、查找替换、跳转到指定行、快速注释。网页项目支持 .html、.css、.js、.json，原生项目支持 .java、.xml。

资源导入

长按项目，选「导入文件」，可以把手机里的图片、音频、视频导入项目的 assets 目录。代码里用 assets/文件名 引用，预览时图片直接显示，音乐和视频直接播放。导入时遇到重名文件会自动编号，不会覆盖。

文件下载

网页里调用 wendustFile.download('assets/文件名')，用户会看到一个深色的下载框，显示文件名和进度条，下载完成后文件保存在系统「下载」文件夹的 wendust 子目录里，用任何文件管理器都能找到。

预览

网页项目：编辑和预览在同一个界面，底部一键切换，预览使用项目自己的文件路径，样式、脚本、资源引用都和真实环境一致。原生项目：点「预览」进入图形化预览，界面按你的 layout XML 实时渲染。

网页控制台

菜单里打开「网页控制台」，可以查看网页的 console 输出和报错信息（包括行号），底部的输入框还能直接执行 JavaScript 语句，用来看变量的值或者测试一段逻辑。

AI 助手

两层设计。默认是内置的离线引擎，不联网也能用：可以回答常见问题、做数学计算、陪你闲聊，还能生成贪吃蛇、计算器、时钟、记事本这类完整的小应用代码，点「复制到项目」直接用。如果你想要更强的回答，去设置里填入自己的 API Key——支持 DeepSeek、智谱 GLM、通义千问的快捷预设，也支持任何 OpenAI 兼容接口，填好测试通过后，AI 对话就走你选的模型，并且带完整的对话历史。

工具箱

编辑器菜单里有 27 个开发工具：JSON 格式化和压缩、查找替换、全项目搜索、颜色选择器、CSS 渐变和阴影生成器、图片转 Base64、时间戳转换、px 和 rem 换算、密码生成器、占位文本生成、URL 编码解码、HTML 表格生成、导出项目 ZIP 等。大部分工具的结果可以一键插回代码。

APK 打包

把网页项目打包成安卓安装包。可以打测试包快速安装，也可以先生成签名证书再打正式包。打包好的 APK 存在项目里，可以直接安装、分享给别人，或者导出到下载文件夹。（原生项目目前支持编辑与图形化预览，暂不提供手机端打包。）

高级功能与每日余额

高级功能中心内置高级模板（记账本/番茄钟/密码生成器）、代码美化、代码压缩、项目 ZIP 导出等，每天 100 点余额、零点自动重置，基础功能不受影响。

上手指南

第一次使用，照下面的步骤走一遍，大约十分钟就能做出第一个应用：

  1. 打开 wendust，点右下角加号，输入应用名、选一个头像。v5.5 起先选项目类型：HTML 网页（选模板，第一次推荐「计算器」）或 Android 原生（自动生成骨架）。
  2. 进入编辑器。左侧是文件列表，中间是代码。网页项目点底部「预览」看效果；原生项目点「预览」进入图形化预览，界面控件直接呈现。
  3. 回到代码页，随便改一处文字，再切预览，确认改动生效。这就是 wendust 的基本节奏：改代码，切预览。
  4. 返回项目列表，长按你的项目，选「导入文件」，从相册选一张图片导入（网页项目）。
  5. 回到编辑器，在 HTML 里写 <img src="assets/你的图片.jpg">，切到预览，图片就显示在应用里了。音频和视频同理。
  6. 觉得满意后，打开菜单，选「APK 打包（测试）」，等进度条走完，安装生成的 APK。它就是一个独立的应用，有自己的图标，会出现在桌面上。

走完这六步，你就完成了从「用别人的软件」到「做自己的软件」的第一步。之后可以试试 AI 助手（说「帮我写一个贪吃蛇」）、网页控制台（看 console.log 输出）和工具箱，这些都在编辑器的菜单里。

进阶一点的玩法：想学安卓开发就创建一个原生项目，把 MainActivity.java 和 activity_main.xml 改成自己的样子，图形化预览里所见即所得；项目做多以后，用「新建文件夹」把文件归类整理；在电脑上打开电脑版，粘贴手机端生成的分享码，把项目变成 EXE 或 DMG 发给朋友。

每个功能的具体说明都在官方文档里，十三个章节覆盖了从安装到原生开发的完整流程，遇到问题先翻文档，再看常见问题。

它做不到什么

提前说清楚，免得下载之后失望：

  • 原生项目（v5.5 新增）支持代码编辑、语法高亮、图形化预览和模拟运行（点运行按钮，按钮事件真的执行），暂不支持在手机上打包 APK。手机 App 打包的是网页项目——打包后本质上是 WebView 壳，调不了摄像头、蓝牙这类原生接口。
  • 不能写后端代码。PHP、Python 等文件类型在 v2.2 已经移除，网页项目保留网页三件套加 JSON，原生项目保留 Java 和 XML。
  • 手机屏幕终究不适合编辑大量代码。它适合小项目、学习和随身修改，大项目还是该用电脑。
  • 不配 API Key 时，AI 助手用的是内置离线引擎，能力有限：认识常见问题、能生成几个内置应用，复杂需求需要自己配 API。

常见问题

自定义语法能创建几个？改名有限制吗？

内置的 xml、java、css、html、js 是基础语法，永久保留且不可删除、不可调整。自定义语法每 5 个月最多创建 1 个，创建后每 7 天只能修改 1 次名字——这是刻意的克制：逼自己想清楚再动手，做出的语言才经得起用。删除自定义语法不返还创建名额。

HTML 教程要联网或付费吗？

不用。96 篇教程全部内置在应用里，离线可看，免费无额度消耗。每篇的练习可以直接在教程页里写代码、运行、看参考答案，不用切去编辑器。

原生项目和网页项目怎么选？

新建项目时选择。网页项目用 HTML/CSS/JS，模板丰富，可以打包成 APK 安装到手机；原生项目用 Java 写逻辑、XML 写界面，有语法高亮和图形化预览（事件、文字、图形都能渲染），适合学习安卓开发和搭建真实界面，目前暂不支持手机端打包。

原生项目的图形化预览支持什么？

它解析 res/layout 下的 XML，把线性布局、文本、按钮、输入框、复选框、开关、进度条等渲染成真实控件——背景色、文字颜色、字号、粗体、圆角、内边距都会呈现。布局里写了 android:onClick 的按钮可以点击，会演示事件的触发。改完 XML 保存后回到预览页刷新即可。

免费吗？

应用本身免费，没有付费功能。AI 助手如果配自己的 API Key，费用由你的 API 账户产生。

AI 助手联网吗？

默认不联网，用的是打包在应用里的离线引擎。在设置里填了 API Key 之后，AI 对话才走你填的接口。

打包出的应用还有水印吗？

没有。v12.0.8 起彻底移除了水印，打包出的应用干干净净，历史项目重新打包也会自动清掉旧水印。

打包出的应用里点链接、下载文件正常吗？

正常。v12.0.8 起所有网页链接都在应用内直接打开（不会再弹出系统选择器），下载链接自动走系统下载管理，通知栏可见进度，不会出现"网页无法加载"的白屏。

打包出的应用闪退怎么办？

v12.0.5 已彻底修复：此前部分项目打包出的 APK 在安卓 11 及以上系统因资源文件对齐问题无法正常启动（是否触发与项目名称长度有关，看起来时好时坏）。升级到 v12.0.7 后重新打包即可，所有项目统一可靠。

打包的 APK 能发给别人吗？

能。测试包和正式包都可以直接分享 APK 文件，对方安装即可。正式包用自己的签名证书签名，升级时用同一个证书即可覆盖安装。

手机 App 和电脑版、在线版有什么区别？

手机 App 打包免费不限次数、去水印免费，资源导入支持手机里的任何文件；电脑版和在线版每日 10 次打包额度。三个版本的核心编辑能力一致，项目通过分享码互通。电脑版独有 EXE（Windows）和 DMG（macOS）打包，在线版无需安装、打开浏览器就能用。

支持哪些资源格式？

图片：png、jpg、gif、webp、svg、bmp。音频：mp3、wav、ogg、m4a、aac、flac。视频：mp4、webm、mov、mkv、avi。其他任意文件也可以导入并作为下载文件提供。v3.0 起导入会自动分类到 音乐 / 视频 / 图片 / 文件夹，重名文件自动加序号，不会互相覆盖。

还需要下载资源包吗？

不需要。v5.3 起架构升级，所有必需组件已直接打包进安装包，安装即可用。从旧版本升级上来会自动清理残留的资源文件，释放手机空间。

高级功能的每日余额是什么？

高级功能（高级模板、代码美化、代码压缩、项目 ZIP 导出等）每天有 100 点共享额度，用一次扣一次：高级模板 10 点、代码美化 5 点、代码压缩 3 点、ZIP 导出 5 点、代码片段 2 点。每天零点自动重置，不需要签到、不联网、不登录，余额存在手机本地。基础功能（编辑、预览、打包 APK、云端、AI 助手）永远免费，不消耗额度。

项目数据存在哪里？换手机怎么办？

项目全部存在手机本地，不上传服务器。换手机时用分享码把重要项目迁移过去：每个项目生成一段文本码，新手机上粘贴导入即可完整恢复。

能离线用吗？

编辑、预览、打包全程离线可用，不联网也完全正常。只有 AI 助手（配了 API Key 时）需要网络。

三个版本，怎么选

手机 App、电脑版、在线版各有分工，按你的使用场景选择，也可以搭配着用：

  • 手机 App（主推）——随时随地的完整开发环境。编辑、预览、导入手机文件、打包 APK 全部免费不限次，v5.5 起还支持 Android 原生项目开发。适合绝大多数场景。
  • 电脑版——浏览器打开即用（官网首页进入），独占 EXE / DMG 打包能力。想把网页应用发给 Windows 或 Mac 用户？电脑版一键打包成双击即用的程序。每日 10 次打包额度。
  • 在线版——零安装的轻量入口。临时写段代码、测试一个想法、不想装任何东西时用它。项目可一键生成分享码带走。

三端项目通过分享码互通，同一个项目可以在手机上起稿、电脑上打包成 EXE 发给朋友。

四种打包格式

wendust 支持把同一个网页项目打包成四种格式，覆盖主流平台：

  • APK（安卓）——手机 App 直接打包，v1 + v2 双签名，安卓 5.0 以上均可安装。测试包即装即用，正式包用你自己的证书签名，可覆盖升级。
  • EXE（Windows）——电脑版打包。单文件便携程序，双击自动调起浏览器运行应用，绿色免安装。
  • DMG（macOS）——电脑版打包。标准 ISO9660 磁盘镜像，双击挂载后打开 pc.html 运行，符合 Mac 用户习惯。
  • AppImage（Linux）——官网直接下载。自解压脚本 + 浏览器，下载后加执行权限即可运行。

所有格式的打包都在本地完成，代码不上传任何服务器。
