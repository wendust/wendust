一、安装与首次启动

wendust 是一个安卓应用，安装包（APK）可以从官网首页下载。因为不是应用商店分发，部分手机安装时会提示「未知来源」，在系统设置里允许当前浏览器安装应用即可，这是安卓的标准流程，不会有安全问题。

v5.3 起安装后直接进入主界面，没有任何前置下载（旧版需要下载的 200MB 资源包已打包进安装包，从旧版本升级会自动清理残留文件）。安装包约 10MB，下载即装即用。

v5.2 及更早版本首次启动需要下载 200MB 资源包；升级到 v5.3 后不再需要，旧资源文件会被自动清理。

二、十分钟做出第一个应用

1. 新建项目

在主界面点击右下角悬浮按钮（FAB）创建项目，填写应用名称并设置头像。初次使用建议选择「计算器」模板——该模板为可完整运行的示例应用，便于验证开发全流程；也可选择空白模板从零构建，或通过「输入分享码」导入既有项目。

2. 认识编辑器

进入编辑器后，左侧是文件树，中间是代码区，底部是「代码 / 预览」切换标签。默认的三个文件就是网页开发的经典三件套：

  • index.html — 页面结构（骨架）
  • style.css — 样式（皮肤）
  • script.js — 逻辑（灵魂）

3. 改代码看效果

把 index.html 里的标题文字改成任何你想要的，切到底部「预览」标签——改动立即生效。改完代码切预览会自动刷新，不需要手动点运行。

4. 打包安装

在编辑器右上角菜单选择「打包测试 APK」，输入大于当前值的版本号，等待构建完成。生成的 APK 可直接安装至设备，此时应用即为独立程序：具有独立图标、显示于桌面，并支持分发给任意用户安装。

三、文件管理与本地云盘

文件管理在 v3.0 重点重做、v3.1 起又加入了独立的本地云盘。项目内导入的文件自动归类，项目之外还有一个不限容量的私人云盘。

自动分类

通过「文件 → 加号 → 导入文件」或首页「长按项目 → 导入文件」选择的文件，会按类型放进对应文件夹：

文件类型去处代码里的引用路径
HTML / CSS / JS / JSON项目根目录直接用文件名
MP3 / WAV / FLAC 等音频assets/音乐/assets/音乐/文件名.mp3
MP4 / MOV / MKV 等视频assets/视频/assets/视频/文件名.mp4
JPG / PNG / GIF 等图片assets/图片/assets/图片/文件名.jpg
TXT / MD / PDF / DOC 等文档assets/文档/assets/文档/文件名.txt
其他类型assets/文件/assets/文件/文件名

同名文件不会互相覆盖：如果目录里已经有 音乐.mp3，再导入一个同名文件会自动变成 音乐(1).mp3，彻底杜绝「文件重复」的问题。

新建文件夹

两种方式：在编辑器中依次点击「文件 → 新建 → 新建文件夹」；或长按文件树中的目标目录，选择「新建文件夹」在其内部创建。

重命名

长按文件树里的任何文件或文件夹，选「重命名」。重命名后代码引用需要同步修改。

删除

同样是长按，选「删除」。删除文件夹会连带里面的全部内容，系统会弹窗确认。

在代码里放一首音乐：<audio src="assets/音乐/我的歌.mp3" controls></audio>。放一张图片：<img src="assets/图片/照片.jpg">。预览和打包后的 APK 里都能正常加载。

本地云盘（v3.1 起）

主菜单里的「本地云盘」是一个独立于项目的私人存储空间，容量不限、数据全部在手机本地：

  • 新建文档——创建 Markdown 文件，编辑器底部有「Markdown 预览」按钮，实时渲染标题、列表、代码块、粗斜体和链接
  • 新建文件夹——在当前位置建立子目录，可多级嵌套
  • 导入文件——任意类型，多选批量导入
  • 导入文件夹——从系统文件选择器挑一个整文件夹，递归导入全部内容并保持原目录结构
  • 下载——长按文件或文件夹导出到系统「下载」目录；文件夹自动打包成 ZIP
  • 导航——点文件夹进入，返回键或工具栏箭头逐级返回

云盘与项目资源相互独立：云盘文件不参与 APK 打包，适合存笔记、备份、常用素材；要用到项目里就从云盘下载后按第一章的方式导入项目。

四、预览与全屏

底部「代码 / 预览」标签随时切换。预览工具栏有三个模式按钮：

  • 手机 — 按手机屏幕宽度渲染（默认）
  • 电脑 — 按桌面宽度渲染，方便测试响应式布局
  • 全屏 — 沉浸式全屏预览，隐藏状态栏和导航栏，右上角有半透明退出按钮，按返回键也可以退出

预览里的 console.log、报错信息可以在「网页控制台」（编辑器菜单）里看到，控制台底部还能直接执行 JS 代码。

预览页面里的文件链接（比如 <a href="assets/文档/说明书.txt">）点击后直接下载到系统「下载/wendust」目录，不弹对话框。

五、打包 APK

编辑器右上角菜单提供两种打包：

  • 打包测试 APK — 用内置调试证书签名，适合自己装、发给朋友测试
  • 打包正式 APK — 可配置自己的签名证书（设置里管理），适合正式发布

打包前需要设置应用头像（长按项目 → 更换头像）。版本号必须大于当前版本号，系统会自动填好建议值。

去水印是免费的：打包时勾选「去水印」即可去掉右下角的 made by wendust 标记，没有任何次数限制或付费。

手机 App 端打包不限次数。电脑版和在线版每天各有 10 次打包额度，第二天自动重置。

打包出的 APK 如果要在应用商店发布，记得用「正式打包」并保管好你的签名证书——同一证书才能发同一应用的更新版。

六、分享码：三端互通

分享码是 wendust 的项目传输机制：以文本形式编码项目全部代码文件，全程不经过服务器，可通过微信/QQ 等即时通讯工具直接传递。

格式

年-月-日-时:分:秒:毫秒-随机三位数-来源平台-WDZ编码内容

来源平台会标注这段码的出生地：AndroidAPP（手机 App）、在线（网页版）、PCAPP（电脑版）。

怎么用

  • 导出：手机 App 长按项目 → 复制分享码（自动写入剪贴板）；网页版点击「分享」。
  • 导入：在任一端创建项目时选择「导入分享码」并粘贴即可；若剪贴板中已包含有效分享码，App 端将自动填充。

分享码只包含代码文件（HTML/CSS/JS 等），图片音乐等资源因为体积大不包含在内——把项目发给朋友后，让对方自己导入同名资源即可。

七、编辑器三连击（v11.0.0 新增）

v11.0.0 功能大版本，编辑器三项能力升级，同时 wendustAI 网页服务停止运营：

  • 查找 — 编辑器菜单选择「查找」，输入关键词循环定位并高亮匹配，移动端找代码不再靠肉眼。
  • 自动保存 — 切换应用、锁屏、退出的瞬间自动保存当前文件，忘记保存丢代码成为历史。
  • 导出单文件网页 — 菜单选择「导出单文件网页」，CSS 与 JS 自动内联进一个 HTML，生成后直接分享，对方浏览器打开即看。

wendustAI（wendustai.surge.sh）已停止运营，App 内 AI 联网配置入口同步移除。产品聚焦核心开发体验：写代码、看效果、出安装包。

八、工具箱

编辑器菜单里的「工具箱」有 26 个开发工具，常用的包括：

  • 代码片段库、HTML 表格生成器、Meta 标签生成器
  • CSS 渐变生成器、阴影生成器、颜色选择器
  • JSON 格式化/校验、Base64 编解码、时间戳转换
  • 下载按钮模板（一键插入带进度条的深色下载按钮）
  • 设备信息、正则测试、密码生成等

九、电脑版与在线版

除手机 App 外，wendust 有两个「轻量兄弟」，适合不同的使用场景：

手机 App电脑版在线版
大项目支持（自动适配性能）支持（IndexedDB 大容量存储）支持
打包 APK不限次数每日 10 次每日 10 次
打包 EXE / DMG—支持—
AI 助手有无无
分享码AndroidAPPPCAPP在线

电脑版为单文件网页应用：从官网下载 .exe（Windows）、.dmg（macOS）或 .AppImage（Linux）后即可直接运行，无需安装。Windows 版启动后将自动在默认浏览器中打开 wendust PC；macOS 版需先挂载磁盘镜像，再打开其中的 pc.html。在线版在浏览器中访问官网「在线编程」页面即可开始开发。

电脑版的打包对话框支持三种输出：APK（安卓安装包）、EXE（Windows 便携程序）、DMG（macOS 磁盘镜像）。三者共享每日 10 次的打包额度。生成的 DMG 是标准 ISO9660 镜像，在 Mac 上双击挂载即可，Windows 和 Linux 用户也可以用 7-Zip 等工具打开它。

EXE 和 DMG 里装的就是你的项目网页本身，收到的朋友双击运行即可，不需要安装 wendust，也不需要任何开发环境。

十、高级功能与每日余额

v5.3 新增「高级功能」中心，入口在编辑器菜单和主菜单里。所有高级功能共享每日 100 点的余额，零点自动重置：

  • 高级模板（10 点）——记账本、番茄钟、密码生成器三个完整可运行的高级应用模板，一键插入当前项目
  • 代码美化（5 点）——把压缩成一团的 HTML / CSS / JS 重新排版成缩进清晰的规范格式
  • 代码压缩（3 点）——去掉注释和多余空白，体积减小、加载更快，适合打包发布前使用
  • 项目 ZIP 导出（5 点）——整个项目（含资源）打成一个 zip 导出到下载目录，方便备份或转到电脑
  • 专业代码片段（2 点）——Toast 提示、深色模式切换、LocalStorage 存储三套常用代码
  • 今日统计（免费）——查看当前余额和今日消耗明细

余额与消耗记录只存在手机本地，不联网、不登录、不签到。每日额度用完时，高级功能当天不可用（基础功能不受影响），零点自动恢复 100 点。v5.3 起资源包下载也一并取消——安装即用。

十一、Android 原生项目（v5.5 起）

v5.5 新增的第二条开发路线。新建项目时先选项目类型：

  • HTML 网页 — 原有路线：模板起步、网页三件套、打包 APK
  • Android 原生 — 用 Java 写逻辑、XML 写界面，更接近真正的安卓开发

原生骨架

选择原生后不会再出现模板选择，直接生成一套可读性强的完整骨架：

我的应用/
├─ AndroidManifest.xml          应用清单（包名、入口 Activity）
├─ java/com/wendust/我的应用/
│  └─ MainActivity.java         入口：一个按钮 + 点击计数 + Toast
└─ res/layout/
   └─ activity_main.xml         界面布局：垂直线性布局 + 文本 + 按钮

语法高亮

Java 和 XML 文件都有语法高亮：关键字紫色、字符串绿色、注释灰色、XML 标签红色、属性橙色，One Dark 配色，深浅主题下都清晰。

新建文件

原生项目里新建文件只提供 .java 和 .xml 两种类型，新建弹窗和提示会自动切换成「原生文件」——保持工程结构纯净，不会混进无关文件。

图形化预览

点底部的「预览」标签，原生项目会打开图形化预览：读取 res/layout 下的 XML，把布局渲染成屏幕上的真实控件：

  • 布局 — 线性布局（水平/垂直）、居中、内边距、子控件间距
  • 文字 — TextView 的文字内容、字号、颜色、粗体；EditText 输入框；Button 按钮
  • 图形 — 背景色块、圆角、ProgressBar 进度条、Switch 开关、CheckBox 复选框
  • 事件 — 布局里写了 android:onClick="方法名" 的按钮可以点击，触发时会弹出「已触发事件」提示，交互逻辑看得见摸得着

状态栏显示渲染统计信息（控件数量与耗时）。修改 XML 并保存后，返回预览页点击「刷新」即可加载最新界面。

真实模拟运行（v6.0）

点击「运行」后，预览器将解析 MainActivity.java 中的事件处理代码并在预览环境中实际执行：findViewById 控件绑定、变量自增（count++）、setText 动态更新界面文本、Toast 提示等。点击预览中的控件即可观察到界面状态的实际变更。当前支持基础语法结构，条件与循环等复杂控制流仍需真机验证，后续版本将逐步扩展支持。

云盘文件徽标（v6.0）

本地云盘的文件图标从表情符号换成类型徽标：文件夹金色 D、网页蓝色 WEB、图片绿色 IMG、音频紫色 AUD、视频红色 VID、文档橙色 DOC，Java 和 XML 有专属徽标（JV / XML），一眼分清文件类型。

原生项目当前支持代码编辑、语法高亮与图形化预览，暂不支持在设备端构建 APK（打包入口将显示相应说明）。如需生成安装包，请使用 HTML 项目路线。

十二、性能与设备适配

3.0 版本开始，wendust 会自动检测你的手机配置并标注性能等级：

  • 高性能 — 内存充裕的设备，所有功能全开
  • 标准 — 绝大多数设备，默认体验
  • 省电模式 — 低内存设备，超大文件编辑时给出提示

等级可以在「设置 → 关于」里查看。大型项目（几十个文件、上 MB 的代码）在「省电模式」设备上建议把大文件拆分成多个小文件，体验会流畅很多。

为什么大文件会卡？手机的文本编辑控件渲染超大文本时的开销远大于桌面浏览器。经验值：单个文件保持在 300KB 以内，任何设备都流畅。

十三、主题与外观

设置里的「主题」提供三个选项：

  • 跟随系统（默认）— 系统切深色它就深色
  • 浅色 — 白底深字
  • 深色 — 暗底亮字

选择即时生效，无需重启。3.0 移除了旧版的「界面颜色」自定义（换成统一的品牌色），同时修复了浅色模式下部分按钮文字看不清的问题。

十四、wendustJS 原生能力（v14.2.0 新增）

wendustJS 让你的 JavaScript 直接调用手机原生能力。打包 APK 时自动内置到你的项目里——无需引入任何文件；编辑器预览与全屏预览中同样自动生效。全局对象为 wendust。

// 显示系统级提示
wendust.toast('保存成功');
// 震动 300 毫秒
wendust.vibrate(300);
// 设备信息（返回 Promise）
wendust.deviceInfo().then(d => console.log(d.model));
// 复制到剪贴板（返回 Promise）
wendust.copy('要复制的文本').then(() => wendust.toast('已复制'));

能力清单

  • wendust.toast(text) — 系统提示。预览与打包后均可用
  • wendust.vibrate(ms) — 震动指定毫秒。预览与打包后均可用
  • wendust.copy(text) / wendust.paste() — 剪贴板读写。预览与打包后均可用
  • wendust.deviceInfo() — 系统版本、SDK、机型、屏幕。打包后返回真实信息
  • wendust.share(text, subject) — 调起系统分享。预览与打包后均可用
  • wendust.camera() / wendust.pickImage() — 拍照 / 相册选图。打包后可用
  • wendust.locate() — 定位（自动申请运行时权限）。打包后可用
  • wendust.saveFile(data, fileName) — 保存到系统「下载/wendust」。打包后可用

预览中调用需要系统授权的能力时，会得到明确的「打包 APK 后即可调用」提示，不提供假数据。打包出的 APK 零水印、无任何附加标识。

快速体验

模板中心已内置「wendustJS 演示」模板，五个按钮对应五项能力，创建项目即可对照学习。

十五、积木编程（v14.3.0 上线 / v14.4.0 扩编）

不用记语法，像搭积木一样把网页逻辑拼出来：选一块积木、填上参数、排好顺序，点「生成代码」就变成真正的 JavaScript。生成文件为 blocks.js，并自动挂载到 index.html——与手写代码共存，重新生成即更新，其他文件不受影响。

入口

主界面顶栏「积木」、设置 > 更多功能「积木」行、编辑器菜单「积木」三处均可进入，选择项目后开始搭建。积木用于网页项目；原生项目继续用 Java 编辑器。

积木清单（55 种）

  • 事件 — 当页面加载完成 / 当点击元素（填 CSS 选择器）/ 每隔秒数执行
  • 动作 — 弹窗消息 / 原生提示与震动（wendustJS）/ 设置元素文字 / 设置元素样式 / 显示、隐藏、切换元素 / 打开链接
  • 变量 — 设置变量（数字或文本）/ 变量增加一个数
  • 控制 — 如果（比较变量与值，可带否则）/ Switch 匹配 / 匹配值与其余情况 / 循环 N 次 / 等待秒数 / 当条件成立就循环（内置一万次防卡死护栏）/ 跳出循环
  • 动作扩展（v14.4.0） — 播放声音 / 设置背景图 / 读取元素文字存入变量 / 读取输入框内容存入变量 / 设置元素属性 / 滚动到元素 / 设置网页标题 / 复制到剪贴板（wendustJS）/ 分享文本（wendustJS）
  • 变量扩展（v14.4.0） — 随机数存入变量

Switch 怎么用

先「设置变量」或用现有变量，再放一个「Switch 匹配」块并填变量名；在 Switch 里点「放入子块」添加「匹配值」——填上可能的取值，把命中后要做的积木放进该分支；需要兜底就再加「其余情况」。程序运行时按变量的实际值走对应分支，和手写 switch/case 完全等价。

编辑工具（v14.4.0）

每块积木带「复制」（连同子块整棵克隆，插到原块后面）；编辑器菜单有「撤销」（回退最近结构改动，最多 60 步）、「预览代码」（生成前先看 JavaScript 原文，满意再写入）、「清空积木」与「帮助」。

纯积木项目（v14.4.0）

新建项目时选「积木」类型：创建即自带挂载好的壳页面与起步积木（页面加载后向界面写一句话），打开积木编辑器直接搭逻辑，点「生成代码」即可运行——全程不碰代码。

生成与修改

点「生成代码」时，积木树转译为 blocks.js 写入项目并在 index.html 挂载引用。blocks.js 由积木生成，手改内容会在下次生成时被覆盖；需要手写逻辑时直接写自己的文件或编辑器里的其他代码，互不影响。预览与打包均可直接运行生成的代码。

十八、常见问题

打包失败怎么办？

3.0 已经修复了部分机型（如真我 V30）的签名兼容问题。如果仍然失败，注意错误提示文字：提示「版本号」相关的按提示调大版本号重试；提示存储相关的检查手机剩余空间（打包需要约等于项目两倍的临时空间）。

安装打包出来的 APK 提示「未安装」？

最常见原因是手机上已经装过同包名的旧版本但签名不同。先卸载旧版再装新版。自己手机上测试时尽量一直用同一种打包方式（测试包或正式包），不要混用。

预览白屏？

打开「网页控制台」查看错误信息。多数问题由 JavaScript 语法错误引起，控制台将显示对应行号。

导入的文件在预览里加载不出来？

检查引用路径是否带了分类文件夹名，例如音乐文件要写 assets/音乐/文件名.mp3，不能只写文件名。路径里的大小写也要完全一致。

分享码导入失败？

请确认已完整复制分享码（自日期前缀至编码结尾）。部分即时通讯工具会对长文本折行或截断，缺失任意字符均将导致解码失败。App 端导入界面可自动识别剪贴板中的分享码。

原生项目能打包 APK 吗？

原生项目支持代码编辑、Java/XML 语法高亮、图形化预览和模拟运行，暂不支持在手机上打包 APK。想在手机上直接出安装包的应用，用 HTML 网页项目即可。

原生项目的预览和真机效果一样吗？

图形化预览按布局 XML 渲染真实控件，文字内容、配色、间距、进度条、开关及按钮交互反馈均可直接查看。但预览环境不执行完整 Java 代码——业务逻辑需通过真机验证。

资源包下载中断了？

v5.3 起已移除资源包下载机制，该问题不复存在。旧版本升级至 v5.3 后，未完成的资源文件将被自动清理。
