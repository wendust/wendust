Karel 是什么

Karel 是一台住在网格世界里的机器人。你用指令指挥它：前进、转弯、捡起或放下锥桶。程序写完点运行，机器人一步一步演给你看——写对写错，当场见分晓。

它是斯坦福大学计算机系新生的第一门课，一用就是几十年。原因很简单：反馈直观，同时把编程真正的地基——顺序、循环、条件、函数——全部练到。这四件事，换任何一门语言都绕不开。

wendust 里的 Karel 用 Python 风格缩进写法，程序会自动转译成 Lua 运行。学完 Karel，再看 Python 或 wendust 的 Lua 脚本，看到的将不是陌生符号，而是熟人。

三分钟上手

第一步：新建项目 → 选择「Karel 机器人」模板。
第二步：打开 karel.karel，里面有一段能直接跑的起步程序。
第三步：点预览，看机器人捡起锥桶再送回起点。改几行指令再跑，就是学编程的全部节奏。

指令总表

类型指令作用
动作move()朝当前方向前进一格
动作turn_left()原地左转 90 度
动作turn_right()原地右转 90 度
动作put_beeper()从包里拿出一个锥桶放在脚下
动作pick_beeper()捡起脚下的一个锥桶
判断front_is_clear() / front_is_blocked()前方是否能走
判断left_is_clear() / right_is_clear()左方 / 右方是否能走
判断beepers_present()脚下是否有锥桶
判断beepers_in_bag()包里是否还有锥桶
判断facing_north() facing_south() facing_east() facing_west()是否朝某个方向

判断放在 if 或 while 里用，配合 not 取反，比如 while not beepers_present():。

世界声明（写在文件顶部）

声明写法说明
世界大小world 宽 高例如 world 6 6，最大 40。机器人出生在左下角，朝东
放锥桶beeper x y 数量在格子 (x, y) 放锥桶
砌墙wall x1 y1 x2 y2横向一段：这排格子的左侧都砌上墙；纵向一段：这列格子的上方都砌上墙
注释# 内容井号后面是给人看的，机器人不执行

格子坐标从 (1, 1) 开始，x 是从左往右，y 是从下往上。撞墙不会穿过，程序会停在出错的那一步并提示原因。

起步程序逐行读

# 一直前进，捡起路上的锥桶，再送回起点放下
world 6 6
beeper 4 1 1

def run():
    while not beepers_present():
        move()
    pick_beeper()
    turn_left()
    turn_left()
    for i in range(3):
        move()
    put_beeper()

def run(): 是入口，点运行后从这里开始执行。while not beepers_present(): 意思是"脚下没锥桶就一直前进"——机器人在 (2,1)、(3,1) 各走一步，到 (4,1) 发现锥桶，循环停，捡起，掉头走三步回起点放下。共 10 步，一步不多。

八个练习，从易到难

1. 正方形巡游

def run():
    for i in range(4):
        move()
        move()
        move()
        turn_left()

练：for 循环与转向。把"走三步转一次"重复四轮，机器人画出一个正方形回到原点。

2. 翻倍捡锥桶

world 5 5
beeper 3 3 2

def run():
    move()
    move()
    while beepers_present():
        pick_beeper()

练：while 直接条件。脚上叠了两个锥桶，全捡进包。

3. 绕墙走廊

world 6 3
wall 3 1 3 1
beeper 5 1 1

def run():
    while not beepers_present():
        if front_is_clear():
            move()
        else:
            turn_left()
            move()
            turn_right()

练：if/else 与绕障。正前方被墙挡住时，左移一格绕过去再回正。把 wall 改长一点，难度立刻上来。

4. 自定义函数：right_side()

def turn_right():
    turn_left()
    turn_left()
    turn_left()

def run():
    move()
    turn_right()
    move()

练：def 封装。语言只给左转，右转就自己造一个——这就是函数的意义：把常用动作打包起名字。

5. 沿墙爬行

world 5 5
wall 2 1 2 5

def run():
    while front_is_clear():
        move()
    while not front_is_clear():
        turn_left()
    move()

练：多条件组合。向东走到墙根，原地左转到墙消失的方向再前进。把墙改成竖排，机器人会贴墙向上走。

6. 铺一条锥桶路

def run():
    for i in range(4):
        put_beeper()
        move()

练：边走边放。起步时给 beeper 1 1 10 让包里有货，机器人身后留下一条路。温故：pick 是捡，put 是放。

7. 清空整格再前进

world 5 5
beeper 2 1 3
beeper 4 1 2

def clean_here():
    while beepers_present():
        pick_beeper()

def run():
    clean_here()
    move()
    clean_here()

练：函数复用。两个格子叠了不同数量的锥桶，同一个 clean_here() 清两处——写一次，到处用。

8. 综合任务：投递员

world 6 6
wall 4 2 4 6
beeper 6 1 1

def turn_right():
    turn_left()
    turn_left()
    turn_left()

def run():
    while not beepers_present():
        if front_is_clear():
            move()
        else:
            turn_right()
            move()
            turn_left()
    pick_beeper()
    turn_left()
    while front_is_clear():
        move()
    for i in range(5):
        move()
    put_beeper()

练：全要素组合。沿东路前进，遇墙绕行，拿到锥桶后一路向北再向西送回角落。跑通它，你已经把顺序、循环、条件、函数全用了一遍。

常见报错

撞墙了（第 N 步）

机器人往墙或边界外走。对照提示的步数，数一数它在第几格。墙的位置用 wall 声明核对。

缩进不对齐（第 N 行）

Karel 用缩进表示代码块，同一层语句必须左边空同样数量的空格。建议一层固定 4 格。

elif/else 必须与 if 对齐

elif、else 要和它对应的 if 写在同一缩进位置。

这里没有锥桶可捡 / 包里没有锥桶可放

捡之前先用 beepers_present() 确认脚下有货，放之前确认包里有。

步数超过 10000，已强制停止

while 循环的条件永远成立，机器人卡住了。检查循环体里有没有让条件发生变化的语句（比如忘了 move）。wendust 会强制停止，防止手机卡死。

Karel 转译失败

检查冒号是否漏了、括号是不是全角中文括号（要用英文括号）、指令名拼写是否正确。
